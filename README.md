# Chainuwat — Turning Ideas into Impact.

Astro static-first bilingual website foundation. See `CHAINUWAT-MASTER-SPEC.md` for product requirements.

## Local development

```sh
npm install
npm run dev
npm run build
```

**Before deployment**: Set repository Actions variables `SITE_URL` to the actual site origin (e.g. `https://username.github.io`) and `SITE_BASE` to `/repository-name/` for a project Pages URL, or `/` for a custom domain/user Pages site. Enable GitHub Pages source **GitHub Actions**. Commit `package-lock.json` generated by `npm install` before the first CI run (`npm ci` requires it).

## Status

This is a **starter foundation, not a complete Release 1**. The content collections are schema-defined but not yet rendered into article/portfolio routes. The About/Work/Insights/Contact pages are placeholders. Resume, real professional claims, contact links, analytics provider, content, sitemap verification and automated content relation checks remain to be completed.

Dependency installation and `astro build` could not be verified in the artifact-generation environment because the npm registry was unreachable. Validate on a network-enabled machine before publishing.

## Homepage implementation
The bilingual editorial homepage is implemented with reusable Astro components and scoped CSS. A typographic portrait placeholder is intentionally used until an approved real photo is provided. Other site pages and portfolio/article data remain incomplete.
